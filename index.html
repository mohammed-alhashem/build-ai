Can Build AI run inside our own VPC or air-gapped?+

Yes. Build AI runs as managed SaaS, in your AWS/GCP/Azure VPC, on-prem, or fully air-gapped. Your code, knowledge graph, and agent runtime stay inside your boundary.

How is this different from a coding assistant?+

Assistants help one developer type faster. Build AI is an end-to-end software factory: it captures intent, builds architecture blueprints, orchestrates agent fleets, and verifies outputs with an audit trail.

Which models do you support?+

All frontier closed and open models (Claude, GPT, Gemini, Llama, Qwen, DeepSeek) plus any OpenAI/Anthropic-compatible endpoint or your own weights.

Can regulators follow what the agents did?+

Yes. Every commit carries signed SLSA L3 provenance linking it back to the original requirement, blueprint, test evidence, and human sign-off.

Do we have to replace our existing tools?+

No. Build AI connects to GitHub, GitLab, Jira, Linear, Slack, and CI, and exposes an MCP server so engineers keep using their favorite editors.
